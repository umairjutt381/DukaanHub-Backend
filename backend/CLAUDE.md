# Backend contributor guide

## Scope

This directory contains the DukaanHub FastAPI backend. Run backend commands
from the repository root so imports beginning with `backend.` resolve
correctly.

```bash
source .venv/bin/activate
uvicorn backend.app.main:app --host 127.0.0.1 --port 8001 --reload
```

Use `PYTHONDONTWRITEBYTECODE=1` for one-off validation commands when possible
so generated `__pycache__` files do not return to the repository.

## Architecture rules

- Keep `app/api/v1/routers` focused on HTTP concerns, dependencies, and
  response handling.
- Put Pydantic request and response models in the matching module under
  `app/schemas` (for example, admin payloads live in `schemas/admin.py`).
- Put business workflows in `app/services`; keep reusable database queries in
  `app/repositories`.
- Define SQLAlchemy tables in `app/models` and use a request-scoped session
  from `app/db/session.py`.
- Register every new router in `app/main.py` with the `/api/v1` prefix.

## Configuration and safety

- Settings come from the repository-root `.env` file via `app/core/config.py`.
- SQLite is the local default. Do not change a database URL, payment settings,
  or credentials without an explicit request.
- Never commit `.env`, uploads, virtual environments, generated bytecode, or
  payment credentials.
- Preserve public request and response shapes unless a change is explicitly
  requested; use `response_model` for stable documented endpoints.

## Validation

After backend changes, at minimum verify imports without creating bytecode:

```bash
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -c "from backend.app.main import app; print(app.title)"
```

Add focused tests under `backend/tests/` when changing business behavior, and
run them with the same bytecode setting.
